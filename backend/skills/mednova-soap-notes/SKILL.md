# MedNova SOAP Notes

Turn a consultation transcript into a clean, reviewable SOAP note that a clinician can sign off in under a minute.

Read `mednova-popia-compliance` first if the transcript contains identifiers.

## Inputs

- Transcript text (may include speaker labels like `DR:` / `PT:` or none at all)
- Optional: practice type (GP, orthopaedic, gynaecology, psychiatry…), patient age/sex, existing problem list
- Optional: target output language (default: English)

## Process

1. **Identify speakers.** Separate clinician and patient statements. If labels are missing, infer from content and mark uncertain attributions.
2. **Handle language.** Transcripts may mix English, Afrikaans, isiXhosa and isiZulu. Translate patient statements into the output language but keep the patient's own words for key symptoms in quotes with a translation, e.g. *"isisu siyaqaqanjelwa" (my stomach is aching)*. Never "clean up" a symptom description into a diagnosis.
3. **Sort into SOAP:**
   - **S — Subjective:** presenting complaint, history of presenting complaint (onset, duration, severity, aggravating/relieving factors), relevant past history, medications, allergies, social history — only as reported.
   - **O — Objective:** vitals, examination findings, point-of-care results that the clinician actually stated or measured. If nothing was examined, write *"No examination findings recorded."*
   - **A — Assessment:** the clinician's stated impression or differential. Do **not** add diagnoses the clinician did not voice. If none stated, write *"Assessment not stated — clinician to complete."*
   - **P — Plan:** investigations, prescriptions (drug, dose, frequency, duration as stated), referrals, patient education, follow-up date.
4. **Flag gaps** in a `Review flags` section: unclear doses, contradictory statements, missing allergies, inaudible segments (`[inaudible 02:14]`), red-flag symptoms mentioned but not addressed.

## Output template

```markdown
**Consultation note** — {date} — {practice type}
**Patient:** {reference ID only, no name unless instructed}

**S:** ...
**O:** ...
**A:** ...
**P:** ...

**Review flags**
- ...

_Draft generated by MedNova AI — requires clinician review and signature._
```

## Rules

- Precision over polish: a missing detail must stay missing and be flagged.
- Use standard abbreviations only when unambiguous (BP, HR, bd, tds); spell out anything else.
- Medication names exactly as said; if a name is unclear, write it as heard and flag it.
- Keep it short — clinicians want scannable notes, not prose.
